## Task 2: 3 variant 真差异化（替换占位 reorder 为真正差分策略）

**根因：** `agents/planner_instant.py:_reorder_for_variant` 只对**无 enriched 的 amap POI** 重排，且策略是简单的"高星沉底/文化置顶"——但当池子里大部分 POI 走 enriched 路径 + must_visit 全部强制 score=999 顶到 head 后，3 variant 看到的 top-N 几乎一致，LLM 自然挑出几乎一样的 stops。

**修法策略：** 不在 reorder 层兜底，把差分提到 `score_poi` 阶段：每个 variant 注入不同 score 偏置（penalty/bonus 系数），让 buckets 内部排序真正不同。

"""v1.10: 3 variant 同 POI 应得明显不同的分数, 让 LLM 真看到差异化候选."""

import pytest
from agents.candidate_pool import score_poi
from dianping.schemas import POI, EnrichedLabel, ParsedIntent


def _intent():
    return ParsedIntent(
        city="深圳", days=1, traveler_type="情侣", time_window="一日",
        anchor_lng=114.057, anchor_lat=22.541, anchor_radius_km=3.0,
    )


def _make(name, star, cats, queue=False, niche=False):
    p = POI(
        openshopid=f"id_{name}", name=name, city="深圳",
        latitude=22.541, longitude=114.057,
        categories=cats, avgprice=100, star=star, business_hour="09:00-21:00",
    )
    tags = []
    if queue:
        tags.append("排队")
    if niche:
        tags.append("小众")
    p.enriched = EnrichedLabel(poi_role="city_essential", planning_tags=tags)
    return p


def test_low_queue_penalises_queue_tag():
    """low_queue variant 看到 '排队' 标签的 POI 应得分明显更低."""
    intent = _intent()
    poi_queue = _make("热门", star=4.8, cats=["景点"], queue=True)
    s_main = score_poi(poi_queue, intent, variant="main")
    s_lq = score_poi(poi_queue, intent, variant="low_queue")
    assert s_lq < s_main - 10, f"low_queue must penalise queue tag: main={s_main} low_queue={s_lq}"


def test_interest_first_boosts_persona_match():
    """interest_first 对匹配 traveler_type 的 POI 加 bonus."""
    intent = _intent()
    poi_match = _make("情侣甜品店", star=4.5, cats=["美食", "情侣推荐"])
    s_main = score_poi(poi_match, intent, variant="main")
    s_if = score_poi(poi_match, intent, variant="interest_first")
    assert s_if > s_main + 10, f"interest_first must boost persona: main={s_main} interest_first={s_if}"
```

    """当 pool 里没有 user 要求的 POI 时, 用 text_search 临时找."""
    # 构造 DayPlan: 3 个 stop, 用户要替换 idx=1 ("江西省博物馆") 为 "南昌之星"
    intent = ParsedIntent(city="南昌", days=1, traveler_type="情侣",

                  avgprice=0, star=4.8, business_hour="09:00-17:00")

        Stop(poi=poi_old),

        day=day, pool=pool, intent=intent, target_idx=1,

新建 `docs/deploy-vps.md`：

```markdown
# VPS 部署清单

**Target:** `https://mt.yikuaibanz.cn/`
**VPS:** 8.136.210.14 / root / 阿里云

## 1. 域名解析
登录阿里云 DNS, 加 A 记录: `mt` → `8.136.210.14`. TTL 600.

## 2. SSH 到 VPS
```bash
ssh root@8.136.210.14
```

## 3. 安装依赖
```bash
apt update && apt install -y python3.14 python3.14-venv nginx certbot python3-certbot-nginx git
```

## 4. clone + venv
```bash
mkdir -p /opt/mtagent && cd /opt/mtagent
git clone https://github.com/<your>/mtagent.git .
python3.14 -m venv venv
venv/bin/pip install -r requirements.txt
```

## 5. .env
```bash
nano /opt/mtagent/.env
# 粘贴 AMAP_KEY / DASHSCOPE_API_KEY / PROFILER_API_KEY 等
chmod 600 .env
```

## 6. systemd
```bash
cp deploy/systemd/mtagent-mock.service /etc/systemd/system/
cp deploy/systemd/mtagent.service     /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now mtagent-mock mtagent
systemctl status mtagent
```

## 7. nginx + letsencrypt
```bash
cp deploy/nginx/mtagent.conf /etc/nginx/sites-available/
ln -s /etc/nginx/sites-available/mtagent.conf /etc/nginx/sites-enabled/
nginx -t
certbot --nginx -d mt.yikuaibanz.cn --non-interactive --agree-tos -m yikuaibanz@gmail.com
systemctl reload nginx
```

## 8. 验收
```bash
curl -sI https://mt.yikuaibanz.cn/ | head -3
# 应返回 HTTP/2 200
```
浏览器开 https://mt.yikuaibanz.cn/ 跑一次南昌输入, 确认 SSE 流式正常.
```
